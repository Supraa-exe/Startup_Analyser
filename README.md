# LAUNCH OR DIE 🚀💀
> *"Your idea has a problem. Find it before the market does."*

An AI-powered startup assumption-testing lab powered by multi-agent simulation.

---

## ⚡ What is LAUNCH OR DIE?

LAUNCH OR DIE is an exploratory assumption-testing workbench for founders. Instead of generating fake market acceptances, vanity TAM numbers, or synthetic revenue projections, LAUNCH OR DIE stress-tests your key business assumptions through multi-agent simulation.

Simulated stakeholder agents (customers, pharmacists, delivery couriers, competitors, and investors) interact, object, and test your core hypothesis. Every extracted finding is backed by verbatim evidence from agent actions and provides practical real-world experiments and continue/pivot/abandon decision gates.

---

## 🛠 Tech Stack

- **Frontend & App Shell:** Next.js (App Router, React 19, TypeScript)
- **Styling & Design System:** Tailwind CSS, Lucide Icons, Custom dark technical theme
- **Multi-Agent Simulation Engine:** [MiroFish](https://github.com/666ghj/MiroFish) (CAMEL-AI OASIS + Zep Cloud)
- **Normalization Boundary:** Application-owned schema in `lib/mirofish/normalize.ts`
- **Persistence (World Archive):** `ArchiveStore` with local JSON store (`.data/`) and MongoDB Atlas interface

---

## 🧭 The Five Product Steps

1. **Launchpad:** Input idea, audience, business model, and the critical assumption to test (includes 1-click Emergency Medicine preset).
2. **Build Your Market:** Shape the simulation seed with 5 preset stakeholder roles (goals, incentives, and operational constraints).
3. **War Room:** Real-time state machine tracking (`QUEUED` → `RUNNING` → `COMPLETED`) with verbatim action logs from simulated Twitter & Reddit feeds.
4. **Verdict:** Actionable, evidence-backed findings grouped into Supporting Arguments, Major Objections, Stakeholder Conflicts, and Unresolved Assumptions.
5. **Strategy Battle:** Sequential comparison of two independent runs (Strategy A vs. Strategy B) evaluating shared themes, unique objections, and real-world validation gates without misleading winner scores.

## 🚀 Quickstart & Setup

### Prerequisites
- Node.js 18+ (tested on Node v22)
- npm 10+
- (Optional for live upstream MiroFish service) Python 3.11, Zep Cloud API key, and OpenAI-compatible LLM API key

### 1. Clone & Install
```bash
cd Startup_Analyser
npm install
```

### 2. Configure Environment (Optional)
```bash
cp .env.example .env.local
```
If `MIROFISH_LIVE_URL`, `ZEP_API_KEY`, and `LLM_API_KEY` are not configured, the application automatically engages its high-fidelity deterministic harness with prominent `SAMPLE — CACHED GENUINE RUN` badging.

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Run Build & Unit Tests
```bash
npm run build
npx tsx --test tests/normalize.test.ts
```
